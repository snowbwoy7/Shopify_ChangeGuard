# Product

## Product
Shopify ChangeGuard

## Positioning
Generic bulk editors help merchants change things. ChangeGuard helps merchants understand and safely approve large changes before they happen.

## Core flow
Select → Define → Preview → Validate → Approve → Execute → Verify → History

## Initial target
Shopify stores with substantial catalogs, variants, metafields, and recurring catalog/pricing changes.

## V1 outcome
A merchant can define a supported bulk change, see exactly what will change and why, approve it, execute it in controlled batches, and verify the result.
