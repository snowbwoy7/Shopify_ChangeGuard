# Development Workflow

Follow the Snow AI Software Development Workflow:

User → Problem → ChatGPT → Validation → Specification → Design → Architecture → Build → Test → Feedback → Iterate

GitHub is the authoritative code source.

Windows + WSL are the local development environment. Docker is used where reproducible local services are needed.

Technical implementation should be performed primarily through the connected development workflow where possible, with local tools used for tasks that require the local environment.
