# Shopify ChangeGuard

Shopify ChangeGuard is a safety-first bulk change planning and execution app for Shopify merchants.

Core promise: **Preview. Understand. Approve. Change. Verify.**

## V1 scope

- Percentage price changes
- Fixed price changes
- Add/remove product tags
- One selected metafield update
- Scope filtering
- Deterministic validation
- Before/after preview
- Explicit approval
- Controlled batch execution
- Post-change verification
- Operation history

## Product principle

Architecture and features follow validated customer needs. AI, agents, APIs, backend complexity, and recurring monetization are not assumed; they are introduced only when evidence justifies them.
